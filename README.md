# Cart Commander Joy

Aplicación de tienda con carrito de compras funcional.

## Descripción

La app presenta una lista de productos con categorías como:

- comida
- agua
- viaje
- cine
- estacionamiento

El flujo esperado es:

1. una página principal con los productos disponibles
2. selección de un producto para ver su detalle
3. agregar el producto al carrito
4. acceso global al carrito desde cualquier pantalla
5. gestión de cantidades, eliminación y métodos de pago
6. confirmación de compra y generación de factura con tiempo estimado de entrega

## Requisitos

- Node.js
- npm

## Instalación

```bash
npm install
npm run dev
```

## Scripts disponibles

```bash
npm run dev
npm run build
npm run preview
npm run lint
```

## Estructura principal

- `src/` — código de la aplicación
- `public/` — archivos públicos
- `src/routes/` — páginas y rutas
- `src/components/` — componentes reutilizables
